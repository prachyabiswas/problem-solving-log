# Problem Solving Log

A running record of the mathematics problems I solve, with full written proofs.

The aim is simple: solve regularly, write every argument out completely, and record what went wrong as carefully as what went right.

## Goal

- Build a steady habit of solving olympiad and undergraduate-level problems.
- Get better at writing complete, rigorous proofs under time pressure.

## What goes in this repository

- Problems from past olympiads and undergraduate competitions (IMC, Putnam-style problems, and others).
- My own written solutions, in full.
- Timed mock tests.
- A review note for every problem, describing where I got stuck and what idea resolved it.

## Repository structure

```
problem-solving-log/
├── algebra/
├── analysis/
├── geometry/
├── combinatorics/
├── mock-tests/
└── README.md
```

Each problem is a single Markdown file named by source and number, for example `imc-2024-d2-p7.md`.

### Status labels

| Label | Meaning |
|---|---|
| Independent | Complete argument found without any hint or published solution |
| Hint-assisted | Complete argument found after a hint or a prerequisite prompt |
| Reconstructed | Proof rewritten from memory after studying a published solution |
| Pending | An unresolved step, missing case, or unjustified inference remains |

## Checklist for a complete proof

1. Every quantifier and the requested conclusion are addressed.
2. Every division has a nonzero denominator, and excluded cases are handled.
3. Every limiting step uses a stated theorem or an explicit error estimate.
4. Counting arguments prove injectivity, bijectivity, or an exact multiplicity.
5. Sharp bounds include a construction and an equality analysis.

## Study routine

- Attempt each problem alone first, within a fixed time limit.
- Compare against a published solution only after the attempt, and record the first gap.
- Revisit each problem after two days, one week, and one month.
- Take a timed mock test every week and write out full proofs.
